# 비교 분석: word-journey.site와 마음결

- 작성: 2026-10-20
- 대상: https://word-journey.site/ ("나의 가치 여정")
- 방법: 공개 페이지의 HTML 소스를 받아 단어 데이터, 단계 로직(`buildPrompt` 등)과 프롬프트 원문을 직접 읽었다. 서비스는 HTML 파일 하나에 스크립트를 인라인으로 넣은 구조다.
- 목적: 마음결이 무엇으로 차별화되어 있고 어디가 겹치는지 정리하고, 다음 작업의 출발점으로 쓴다.

## 1. word-journey 요약

### 1-1. 기본 정보

| 항목 | 내용 |
|---|---|
| 제목·부제 | "나의 가치 여정", "나는 어떤 사람인가요". 공유 미리보기는 "🌿 나의 가치 여정" / "내 인생을 관통하는 5가지 단어" |
| 소요 시간 | 화면 안내 "10~20분 소요" |
| 결과물 | 핵심 가치 단어 5개 + "AI 분석용 프롬프트"(복사 전용) |
| 근거 이론 | 언급 없음 |
| 로그인·저장·공유·결제 | 없음 |
| 개인정보 안내 | 없음. 네이버 애널리틱스(`wcs.pstatic.net/wcslog.js`)가 달려 있음 |

### 1-2. 흐름 (8단계)

| 단계 | 내부 이름 | 하는 일 |
|---|---|---|
| 1 | positive_select | 긍정 단어 200여 개 중 마음에 울림이 있는 20개 고르기 |
| 2 | positive_drop_1 | 20개 중 5개 내려놓기 → 15개 |
| 3 | positive_drop_2 | 15개 중 5개 내려놓기 → 10개 |
| 4 | positive_drop_3 | 10개 중 5개 내려놓기 → 5개 (`positive_core_5`) |
| 5 | negative_select | 원하지 않거나 극복하고 싶은 단어 10개 고르기 |
| 6 | negative_drop | 10개 중 5개 내려놓기 → 5개 (`negative_core_5`) |
| 7 | opposite_select | 남긴 부정 단어마다 같은 묶음의 긍정어 중 "반대편의 힘" 하나 고르기 → 5개 |
| 8 | final_select | 긍정 핵심 5개 + 전환 5개, 총 10개 중 "지금의 나를 가장 잘 담은 5개" 고르기 |

### 1-3. 단어 데이터

- 묶음 52개. 묶음마다 긍정어(`pos`)와 부정어(`neg`)가 짝지어 있다. 긍정 208개, 부정 155개.
- 예: `사랑·헌신·애정·생명 ↔ 집착·죽음`, `희망·소망·꿈·비전 ↔ 절망·낙심·좌절`, `평안·평화·안정·안전 ↔ 불안·초조·혼란`, `정의·공정·평등·자유 ↔ 불의·차별·강요`
- 7단계 '전환'은 이 짝을 이용한다. 부정 단어가 속한 묶음의 긍정어만 고를 수 있다.
- 가치 이론 같은 상위 분류는 없다. 묶음 번호만 있다.

### 1-4. 해석 프롬프트

- 역할: "한 사람의 내면 여정 데이터를 분석하는 깊이 있는 심리 통찰가"
- 망설임 정보를 한 줄로 넣는다: 토글(골랐다 뺀) 횟수가 가장 많은 단계, 가장 오래 걸린 단계와 걸린 초.
- 데이터는 JSON으로 넣는다.
  - `final_positive_5`
  - `journey`
    - `positive_selected_20`, `dropped_positive.step1~3`, `positive_core_5`
    - `negative_selected_10`, `dropped_negative`, `negative_core_5`
    - `opposite_choices[{negative, chosen_opposite}]`
  - `stage_summaries[{stage, duration_ms, total_toggles}]`
- 답변 항목은 6개이고, 문단 형식으로 "구체적이고 따뜻하게" 쓰라고 한다.
  1. **인생 타이틀**: 시적인 한 문장
  2. **확신의 가치 vs 열망의 가치**: `positive_core_5` = 확신, `opposite_choices` = 열망
  3. **내면의 과제**: `negative_core_5` = 직면하고 싶은 그림자. 반대편 긍정어와의 연결
  4. **세 장면 속의 나**: 혼자 / 친구들과 / 직장·역할. 장면마다 할 법한 말 한 문장을 따옴표로 넣고, 아래 소항목을 녹인다.
     - 에너지를 얻는 방식과 소진되는 방식
     - 잘 맞는 사람 유형, 불편한 사람 유형, 싫어하는 대화 분위기
     - 강점, 스트레스 상황, 잘 맞는 조직 문화
  5. **주의해야 할 점**: 빠지기 쉬운 함정, 남에게 주는 부담, 스스로를 소진시키는 방식, 연습하면 좋을 태도. 항목마다 예시를 붙인다.
  6. **이 사람에게 건네는 말**: 한 문단

## 2. 마음결과 나란히 보기

| | word-journey | 마음결 |
|---|---|---|
| 무엇을 보나 | 가치 단어만 | 성격 5요인(Mini-IPIP) + 가치(Schwartz 10가치) + 요즘 기분 + 키우고 싶은 힘 |
| 입력 방식 | 단어 고르기와 덜어내기만 | 5지선다 문항 + 단어 고르기 섞음(D28) |
| 근거 | 밝히지 않음 | 근거 문헌을 밝히고, 검증된 검사가 아니라는 한계도 밝힘(시작 화면 근거 모달, 결과, 프롬프트) |
| 단어 구조 | 긍정·부정 짝 | 가치 단어마다 10가치 중 하나에 연결됨. 이 연결로 앱이 "눈여겨볼 연결"을 계산함(같은 가치 겹침, Schwartz 원형에서 반대인 가치, 키우고 싶은 힘과 남긴 가치의 관계, 내려놓았다가 다시 고른 가치) |
| '열망'의 출처 | 부정 단어의 반대편으로 고른 긍정어 | 5단계에서 가치 카드로 직접 고른 힘 |
| 그림자(부정 단어) | 있음(5·6·7단계) | 없음 |
| 결과 화면 | 단어 5개 목록 | 1순위 가치 그림 카드(10종), 나의 결, 요즘. 자세히 보기에 연결·망설임·근거 |
| AI 연결 | 프롬프트 복사만 | 복사한 뒤 ChatGPT·Gemini·Claude 버튼, 다시 복사, 복사가 막히면 전문 보기와 파일 저장, 인앱 브라우저 안내 |
| 소요 시간 | 10~20분 | 3분 안팎(D23). 20문항으로 늘리는 작업은 아래 4절 참고 |
| 개인정보 | 분석 도구 있고 안내 문구 없음 | 서버·분석 도구·쿠키 없음, sessionStorage만 씀 |
| 해석 수위 | "잘 맞는 사람 유형", "불편한 사람 유형"을 요청함 | 진단, 유형 판정, 타인 비교, 그림에 이름 붙이기를 금지함 |
| 그 밖에 | 공유 제목에 이모지 | 배경음(D34), 노트 속지 디자인, 한 화면 원칙(D31) |

## 3. 차별화가 약한 곳 (겹치는 점)

1. **해석 프롬프트 구성이 거의 같다.**
   - v4(D33)를 만들 때 word-journey 결과물을 기준으로 삼았다. [build-copy-prompt.ts](../src/lib/prompt/build-copy-prompt.ts) 5~6행 주석과 decisions.md의 D33에 기록되어 있다.
   - 겹치는 항목: 한 줄 타이틀, "확신과 열망"(이름까지 같음), 세 장면 속의 나(에너지·관계·일 소항목), 조심하면 좋을 점, 응원 한마디
   - 마음결에만 있는 항목: "나를 이루는 결", "요즘의 나", "이번 주 작은 한 걸음"
   - 두 서비스를 모두 해 본 사람은 AI 답변이 비슷하다고 느낄 가능성이 크다.
2. **고르고 덜어내는 방식이 같은 계열이다.**
   - D28이 "word-journey와 너무 비슷하다"는 사용자 요청으로 1단계를 문항형으로 바꿨지만, 2·3단계(20개 중 5개 → 3개)는 여전히 덜어내기 방식이다.
3. **망설임 데이터가 겹친다.**
   - word-journey: 단계별 머문 시간, 토글 횟수
   - 마음결: 가장 오래 머문 단계, 골랐다가 뺀 단어
4. **word-journey에만 있는 강점이 있다.**
   - 부정 단어로 그림자를 고르고 반대편으로 전환하는 단계가 서사를 만든다.
   - 단어 수가 마음결의 10배가 넘어(긍정만 208개, 마음결 가치 단어는 20개) 고른 결과가 더 개인적으로 느껴진다.

## 5. 차별화 방향 (제안)

**추천: 성격 × 가치 연결을 결과 화면에서 바로 보여 주기.**

- word-journey는 AI 없이는 단어 5개 목록만 남는다. 마음결은 이미 성격 기울기와 가치 구조를 계산하고 있으니, 그 연결을 앱이 직접 말해 주면 AI 없이도 그 자리에서 의미가 생긴다.
  - 예: "새로운 것에 열린 편인데, 1순위로 안정을 남겼어요"처럼 기질과 가치가 맞물리거나 엇갈리는 지점
- 오각형 그래프(D51)와 눈여겨볼 연결(patterns)이 이 방향의 재료다. 결과 카드 또는 자세히 보기 맨 위에 "기질 × 가치" 한두 줄을 두는 안을 검토한다.
- 해석 프롬프트도 word-journey식 항목 구성(타이틀 · 확신 vs 열망 · 세 장면 · 주의할 점 · 건네는 말)을 따르기보다 이 연결을 중심으로 다시 짜는 것을 검토한다. 바꾸면 `prompt.test.ts`의 고정 문구, spec.md §6, decisions.md를 함께 갱신해야 한다.

**그 밖에 검토할 것**

- **소요 시간을 강점으로 유지할지.** 20문항을 유지한다면 시작 화면의 시간 안내를 바꾸고, 짧다는 것 대신 근거와 구조를 강점으로 내세운다. 3분을 지킨다면 10문항으로 돌아가는 안도 있다.
- **그림자·전환 단계 도입 여부.** 서사의 힘은 크지만 word-journey와 더 비슷해진다. 도입한다면 부정 단어가 임상 증상처럼 읽히지 않게 해야 한다(D6, 금지 규칙).
- **"덜어내기" 화면의 차별화.** 예를 들어 단어를 고를 때 그 단어가 어느 가치에 속하는지, 원형에서 어디에 있는지를 결과에서 시각화하는 방식으로 다르게 만들 수 있다.
